# GETAWAY

A compact neon-noir escape game for the browser. Drive the procedural city, take risky jobs, lose the police, and make your own way home.

**Play:** open `index.html` directly or serve this folder with any static server.

**Controls:** WASD / arrow keys drive or move · Space handbrake / jump on foot · E interact / enter vehicles · Shift sprint · C crouch · Esc pause.

The game is intentionally dependency-free and uses relative URLs so it can deploy cleanly to `qynl.github.io/getaways` via GitHub Pages.

See [`GAME_PLAN.md`](GAME_PLAN.md) for the staged build plan.
